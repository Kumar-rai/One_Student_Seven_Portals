ONE STUDENT, SEVEN PORTALS — WEBSITE PROJECT
================================================

Files
-----
index.html          Home page
attendance.html     Attendance instructions
results.html        Marks and results instructions
help.html           Help Centre
css/style.css       Responsive website styling
js/main.js          Mobile navigation and portal-link configuration

How to run
----------
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html, or open the folder in Visual Studio Code.
4. For a local development server, use the VS Code Live Server extension if available.

Important: configure official links
-----------------------------------
The portal buttons are intentionally not connected to guessed destinations.
1. Open js/main.js in VS Code.
2. Find PORTAL_LINKS.
3. Add the verified official attendance and results URLs.
4. Save and test both buttons.
Only use links confirmed by the institution. Do not put usernames, passwords or private student data in this project.

Project scope implemented
-------------------------
- Four pages: Home, Check Attendance, View Marks & Results, Help Centre.
- No login or account creation.
- Step-by-step generic navigation instructions.
- Direct portal buttons, activated after official URLs are configured.
- Visual-only search bar (not functional).
- Responsive navigation menu for smaller screens.
- No collection or storage of personal academic data.
